Every student should be able to use every part of AI Innovation Lab K-12. The platform is designed to meet the WCAG 2.1 AA accessibility standard and to support the accommodations in students' IEPs and 504 plans.

## Keyboard navigation

Every game, simulation, and evidence task can be completed with a keyboard alone. Drag-and-drop activities have a keyboard alternative, focus is always visible, and there are skip links to jump straight to the main activity.

## Screen reader support

All buttons, charts, and images have text descriptions that screen readers announce. Simulation results are available as a data table as well as a chart, and the AI's hints are read in the same order they appear on screen. The platform is tested with JAWS, NVDA, VoiceOver, and ChromeOS ChromeVox.

## Captions

Every instructional video has captions and a transcript. Questions and hints can be read aloud, with words highlighted as they are spoken, which also supports early and developing readers.

## Typing, speaking, or drawing

Students can respond in the way that works best for them. They can type an answer, speak it and have it transcribed, or draw it on a sketch pad, which is useful for math work and for younger students. Teachers can choose which response options are available for each student.

## Printable activities

Not every school has a device for every student every day. Every game set, simulation worksheet, and evidence task has a printable version that teachers can use offline, along with an answer key. Printed work can be photographed and uploaded later so it still counts toward a student's progress.

## More supports

Teachers can turn on extended time, a reduced-distraction mode that removes animations and sound, larger text, high-contrast colors, and Spanish-language instructions for individual students.
