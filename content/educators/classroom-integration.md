Teachers do not need to rebuild their curriculum to use AI Innovation Lab K-12. Every activity is tagged by grade, subject, and standard, so teachers can search for the unit they are already teaching and find games, simulations, and evidence tasks that fit it.

## How teachers incorporate AI into existing lessons

Most teachers start small. A common first step is replacing a practice worksheet with ten minutes of AI Learning Games at the end of a lesson. Once students are comfortable, teachers add a Project Testing Lab activity as a hands-on part of a unit, or use the Evidence and Explanation Coach to prepare for a research paper or a debate.

A typical week in a class using the platform might look like this:

| Day | Lesson part | Platform tool |
|---|---|---|
| Monday | Teacher introduces the new skill | None, or a 5-minute warm-up game |
| Tuesday | Guided and independent practice | AI Learning Games |
| Wednesday | Small groups with the teacher | Games for students not in the group |
| Thursday | Apply the skill to a question | Project Testing Lab |
| Friday | Explain and defend findings | Evidence and Explanation Coach |

## Examples of curriculum integration

In **2nd grade math**, a unit on place value uses Learning Games where students build numbers with virtual blocks. The class ends the unit by using the Testing Lab to predict how many blocks it would take to build 1,000.

In **7th grade science**, a unit on ecosystems uses the Testing Lab to simulate what happens to a pond when one species disappears. Students then use the Evidence Coach to check a news claim about invasive species in Kentucky waterways.

In **10th grade English**, a persuasive writing unit uses the Evidence Coach for students to test the claims in their own essays before they submit them. This helps students catch unsupported claims before the essay is graded, not after.

In **11th grade U.S. history**, students use the Evidence Coach to compare primary sources about the same event and explain which account is more reliable and why.

## How activities connect to an existing unit

Teachers build an AI Innovation Lab "unit pack" in three steps. First, they choose the standards or skills the unit covers. Second, the platform suggests matching games, simulations, and evidence tasks, which the teacher can accept, remove, or edit. Third, the teacher sets the dates and difficulty range. Unit packs can be shared with other teachers in the same school, so a grade-level team only has to build each unit once.
